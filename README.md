# HomeLifeSync — Release APKs

Prebuilt Android debug builds for the HomeLifeSync prototype, generated by
`build-apks.sh` in the main repo. **Only build artifacts are stored here — no source code.**

| Artifact | Target device | Package | Purpose |
|----------|---------------|---------|---------|
| `home-sync-caretaker-debug.apk` | Caretaker phone | `com.kaushikieee.homelifesync.caretaker` | Command & monitoring app |
| `home-sync-elder-debug.apk` | Elder phone | `com.homelisync.elder` | Native health monitor with live vitals graphs |
| `home-sync-tablet-debug.apk` | Wall/tablet display | `com.homelisync.tablet` | Thin shell loading the caretaker web export at `/tablet` |

## Install

```bash
adb install -r home-sync-<name>-debug.apk
```

> Debug builds. These use open Firebase Realtime Database rules (prototype-only)
> and are not hardened — do not ship this build to production.
